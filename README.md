# Innerly — Psychology-Inspired Wellness Website

A responsive, zero-cost starter website for a psychology-inspired self-reflection/wellness brand.

## Files
- `index.html` — complete website structure and content
- `styles.css` — responsive visual design
- `script.js` — interactive assessment modal, newsletter demo, and toast notifications

## Run it
Simply open `index.html` in a browser.

## Publish it for free
You can upload these files to a static hosting service such as GitHub Pages, Netlify, or Vercel.

## Before launching
1. Replace the demo newsletter form with a real email/form backend.
2. Connect payment checkout if you sell toolkits.
3. Add your final brand name/logo.
4. Have any professional claims and psychology content reviewed for your intended market.
5. Keep the wellness/self-reflection disclaimer and avoid presenting the assessments as diagnosis or treatment.

The assessment in this demo is intentionally a lightweight reflection tool, not a validated psychological test.
